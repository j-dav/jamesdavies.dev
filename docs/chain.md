  Chain — https://thechainpuzzle.com

  A daily number puzzle. Each day you're given a starting number and a target, and three operations to get from one to the other:

  - Flip — reverse the digits (e.g. 123 → 321)
  - Boost — multiply by 2
  - Nudge — add 3

  The challenge is finding the shortest chain. Every player gets the same puzzle each day, so you can compare scores with friends. There's also a practice mode for when one puzzle a day isn't enough, and a hard mode with longer solutions and limited undos.

  Built as a no-backend PWA — puzzle generation, solving, and stats all run client-side. React + Vite, deployed on Cloudflare Pages, works offline.
